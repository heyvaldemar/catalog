# Catalog

Every public deployment template and tool by [Vladimir Mikhalev](https://github.com/heyvaldemar), with its latest release and its own CI badge.

What "under the standard" means for a template here: images pinned by digest as interpolation defaults, so `git pull` delivers the combination the repository has tested; a daily freshness check against the registry and the upstream release list; a deploy job that boots the stack on every change and, before that, starts the previous release on the same volumes and upgrades from it; backups written atomically and restored in a test where there is data to lose; `update.sh` that moves between release tags, refuses to cross a major unattended and names any variable that became required; and a release cut only after all of that is green, carrying what upstream changed, read from its release notes. A daily conformance check runs the rules against every repository; [fleet-ops](https://github.com/heyvaldemar/fleet-ops) refreshes drifted images and cuts the releases.

This file is generated. Nothing in it is a claim of its own: the badge is each workflow's, the release is the tag GitHub has, the date is when it was published.
